# LaTimp

Aplicație web instalabilă (PWA): termenele, plățile și zilele importante la timp, plus idei pentru timpul liber.

- Se deschide din browser și se instalează pe ecranul principal (Android: „Instalează aplicația”; iPhone: Safari → Partajare → „Adaugă pe ecranul principal”).
- Merge și fără internet (service worker în `sw.js`).
- Versiune de test: datele stau doar pe telefon. Contul real, sincronizarea și plățile vin cu legarea la server.

Fișierele sunt generate dintr-un singur build; nu le edita de mână.
